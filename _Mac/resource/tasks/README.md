# MaaSOW 任务清单

每个任务使用一个 JSON 文件，文件名必须与 `id` 一致。这些清单是 MaaSOW
执行器的配置源，`generate_interface.py` 会校验清单并将启用的任务转换成
ProjectInterface V2 任务卡片。

简单任务使用 `handler: "pipeline"`，复杂业务使用 `handler: "python"` 并通过
`extension` 指向 `agent/custom/action/` 中的 `module:function`。

只有会发起行军且需要展示自动补体开关的任务才设置
`"auto_stamina": true`；未设置时 MXU 任务展开项不会显示该复选项。

自动打貔貅：`auto_pixiu` 复用通用大地图导航、出征和自动补体。
前台可输入 1–10000 次（默认 1），自动补体默认关闭；次数按确认小队出发累计，
到达次数即结束，不等待最后一队回城。首次直接进入活动并从出征面板确认队列容量和空闲候选。
后续占用数小于面板确认的队列容量即继续派遣；左上读数不明时重新检查出征面板。
没有可派遣队伍时等待任意一队空闲，最长 900 秒。
从当前活动页签向两侧查找祥瑞聚宝，搜索灵貅后核对藏宝灵貅名称再进攻。
找不到活动或本波目标、补体失败、出征无法确认时停止并报告原因，不盲目重发。

自动玲儿降妖：`auto_ling_er` 从大地图搜索兽潮首领的妖兽洞穴。集结等级默认 1、次数默认 1，支持手动输入；自动补体默认勾选。集结队列提供 1、2、3、4 多选框，默认只勾选 1；仅勾选队列轮转派遣并分别跟踪，未勾选队列不参与。集结次数为所有参与队列的完成总次数，按集结中 → 出征 → 返回 → 连续确认消失计数。等级超出游戏边界、识别不明确或状态超时会停止，不重复点击组队。组队时间沿用游戏当前选项。

玲儿降妖短途兜底：已确认出发或战斗、队伍连续消失但漏采到返回帧时，打开组队面板两次确认原队列的面板头像一致且空闲后计数；仅集结后消失不视为完成。

返回复核成功后复用当前组队面板：先计数并释放旧队列，再按已勾选队列和剩余总次数直接组队；仅在次数完成、复核失败或需要继续观察大地图时关闭面板。
