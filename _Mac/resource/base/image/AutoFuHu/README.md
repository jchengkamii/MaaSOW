# 伏虎降妖定位模板

`locate.png` 来自用户提供的 752×1360 大地图截图，截取左下角活动定位图标中的小怪脸部（原图坐标 121,1051–171,1104），按短边 720 缩放为 48×51。模板不包含圆框和地图背景。

仅在大地图左下方区域匹配，禁止全图兜底，避免匹配地图上的同类怪物。定位入口会随左侧按钮布局上下移动，搜索区域覆盖距底边 130–520 像素的位置；2026-10-21 实机失败截图中的图标位于 (115,923)，原图标区域过低导致漏检，扩大区域后匹配分数为 0.987。进攻图标复用 `Common/March/attack.png`，同时要求带等级和“挑战者”的目标弹窗。

目标较远时，首次定位可能仅移动地图镜头。等待弹窗后若仍确认是大地图默认态，最多补点一次定位入口；已经出现目标弹窗或其他界面时不补点。
